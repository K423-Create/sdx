SDX

Personal trading automation, built for a single account.

What it is

SDX is a private, single-user application that automates rule-based trading on the owner's own cTrader account through the cTrader Open API. It is not a platform, not a signal service, and it does not manage money for anyone else.

How it works

  • Connects to the cTrader Open API over an authenticated, encrypted channel.
  • Evaluates a fixed rule set on closed candles only - no intrabar guessing.
  • Sizes every position from a fixed money-at-risk budget, never a fixed lot.
  • Enforces hard limits: daily loss cap, maximum trades per day, spread and session filters.
  • Attaches server-side stop-loss and take-profit to every order it places.

Safety model

  • One position at a time per instrument. No grid, no martingale, no averaging down.
  • A kill-switch flattens and halts trading once the daily loss limit is hit.
  • A dry-run mode logs decisions without sending any order.

Scope of access

The application requests access to the owner's own trading accounts only (trading scope). It stores OAuth tokens locally on the owner's machine.
